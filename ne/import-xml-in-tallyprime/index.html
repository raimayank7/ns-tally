TallyPrime मा XML फाइल कसरी इम्पोर्ट गर्ने

TallyPrime ले XML फाइलबाट डेटा पढ्न सक्छ (र Release 4.0 देखि Excel बाट पनि)। यो साइटमा बन्ने फाइल XML हुन्। इम्पोर्टमा एक मिनेट लाग्छ, तर क्रम महत्त्वपूर्ण छ: पहिले लेजर, अनि भौचर।

सुरु गर्नुअघि

  • TallyPrime मा कम्पनीको ब्याकअप लिनुहोस्। इम्पोर्टले एकैचोटि धेरै प्रविष्टि थप्छ; ब्याकअप भए पछाडि फर्कन सकिन्छ।
  • सही कम्पनी खोल्नुहोस्, र त्यसको आर्थिक वर्षले भौचरका मिति समेट्छ कि जाँच्नुहोस्।
  • बिलअनुसारको विवरणका लागि कम्पनी फिचर (F11) मा बिलअनुसारको प्रविष्टि खोल्नुहोस् र पार्टी लेजरमा Maintain balances bill-by-bill खुला राख्नुहोस्।

चरण 1: लेजर (मास्टर)

  1. Alt+O (Import) › Masters थिच्नुहोस्।
  2. File Path मा लेजर फाइलको फोल्डर र नाम दिनुहोस्, जस्तै Downloads मा भएको tally-masters-2026-11-05.xml।
  3. उही नामको लेजर पहिल्यै भएमा Tally ले के गरोस् भन्ने छान्नुहोस्: Combine opening balance, Ignore duplicates (तपाईंको राख्ने, हाम्रो छोड्ने) वा Modify with new data (हाम्रोले तपाईंको बदल्छ)। तपाईंको Tally मा यी पार्टी पहिल्यै होसियारीसाथ बनाइएका छन् भने Ignore duplicates छान्नुहोस्।
  4. ब्याकअपमा Yes भन्नुहोस्, Enter थिच्नुहोस्। कतिवटा मास्टर बने, बदलिए वा छोडिए भनेर Tally ले देखाउँछ।

चरण 2: भौचर (ट्रान्जेक्सन)

  1. Alt+O (Import) › Transactions थिच्नुहोस्।
  2. भौचर फाइलको पाथ दिनुहोस् (tally-vouchers-….xml), ब्याकअपमा Yes भन्नुहोस्, Enter थिच्नुहोस्।
  3. ती मितिका लागि Day Book खोल्नुहोस् र केही भौचर आफ्ना बिलसँग तुलना गर्नुहोस्।

Tally ले एरर देखायो भने

  • लेजर अस्तित्वमा छैन: लेजर फाइल पहिले इम्पोर्ट गरिएको थिएन, वा भौचरमा रहेको लेजरको नाम तपाईंको Tally को नामभन्दा फरक छ। "तपाईंको Tally मा भएका लेजरका नाम" मा नाम मिलाउनुहोस्, दुवै फाइल फेरि बनाउनुहोस्, फेरि इम्पोर्ट गर्नुहोस्।
  • भौचरको प्रकार अस्तित्वमा छैन: भौचरले Tally का आफ्नै प्रकार प्रयोग गर्छन्: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note र Journal। ती प्रकार तपाईंको कम्पनीमा सक्रिय छन् कि जाँच्नुहोस्।
  • जोड मिलेन: हरेक भौचरको डेबिट त्यसको क्रेडिटसँग बराबर हुनुपर्छ। यहाँ बनेका फाइल सधैँ मिल्छन्; यस्तो हातले सच्याइएको Excel रजिस्टरमा मात्र हुन्छ। त्यो लाइन मिलाउनुहोस्।
  • उही भौचर दुई पटक इम्पोर्ट गरे दुई पटक बन्छन्। हरेक अवधि एक पटक मात्र इम्पोर्ट गर्नुहोस्।
