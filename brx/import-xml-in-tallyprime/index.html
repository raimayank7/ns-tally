TallyPrime आव XML फाइल माबादि इम्प'र्ट खालायो

TallyPrime आ XML फाइलनिफ्राय डेटा फरायो (आरो Release 4.0 निफ्राय Excelनिफ्रायबो)। बेयाव बानायनाय फाइलफोर XML। इम्प'र्टआव मिनिट मोनसे जायो, नाथाय गेजेरनि सोदोब गोनाङा: गिबिसिन लेजार, उनाव भाउचार।

सिमा जानो

  • TallyPrime आव कम्पानिनि बेकआप ला। इम्प'र्टआ एन्ट्रिफोर मोनसे सायाव दाजाब खालायो; बेकआपआ फिन थानो हायो।
  • गोरोब कम्पानि खेव, आरो बेनि फाइनान्सियाल बोसोरआ भाउचारफोरनि तारिखफोर गोख्रै खालायो नांबे नाय।
  • बिल-वाइज डिटेलनि थाखाय, कम्पानि फिचारआव (F11) बिल-वाइज एन्ट्रि अन खालाम आरो पार्टि लेजारनि थाखाय Maintain balances bill-by-bill अन थां।

स्टेप 1: लेजारफोर (मास्टार)

  1. Alt+O (Import) › Masters प्रेस खालाम।
  2. File Path आव, फल्डार आरो लेजार फाइलनि मुं हो, जेरै Downloads-आव tally-masters-2026-11-05.xml।
  3. बे मुं लोगो लेजार दंब्लाबो Tally-आ मा खालामनो बेखौ सायख': Combine opening balance, Ignore duplicates (नोंथांनिखौ थां, जोंनिखौ खारना) एबा Modify with new data (जोंनिआ नोंथांनिखौ सोलायो)। नोंथांनि Tally-आव बे पार्टिफोरखौ गोरोबै थानाय जाब्लाबो Ignore duplicates सायख'।
  4. बेकआपनि थाखाय Yes बुं, Enter प्रेस खालाम। Tally-आ मास्टार माखासे बानाजाबाय, सोलायजाबाय एबा खारनाजाबाय बेखौ नुजायो।

स्टेप 2: भाउचारफोर (ट्रान्जाक्सन)

  1. Alt+O (Import) › Transactions प्रेस खालाम।
  2. भाउचार फाइलनि पाथ (tally-vouchers-….xml) हो, बेकआपनि थाखाय Yes बुं, Enter प्रेस खालाम।
  3. बे तारिखफोरनि थाखाय Day Book खेव आरो भाउचार खामासेखौ नोंथांनि बिलफोरजों गाहाम नायफिन।

Tally-आ भुल नुजाब्ला

  • लेजार गैया: लेजार फाइल गिबिसिन इम्प'र्ट खालाखै, एबा भाउचारआव दंनाय लेजारनि मुं नोंथांनि Tally-आव दंनाय मुंनिफ्राय गुबुन। “Ledger names in your Tally” आव मुंखौ थाब, फाइल गोननैखौ फिन बानाय, फिन इम्प'र्ट खालाम।
  • भाउचार रोखोम गैया: भाउचारफोरा Tally-नि आफादनि रोखोम बाहायो: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note आरो Journal। नोंथांनि कम्पानिआव बे रोखोमफोर एक्टिभ नांबे नाय।
  • टोटाल गाहाम जायाखै: भाउचार गासैनि डेबिट बेनि क्रेडिटजों समान जानो नांगौ। बेयाव बानायनाय फाइलफोरा जेरैबो बेलेन्स जायो; बेयो हात्तिनि एडिट खालामनाय Excel रेजिस्टारआव जानो जायो। बे रोखौ थाब।
  • भाउचार बे गोनाखौ गोननै इम्प'र्ट खालाब्ला गोननै बानाजायो। समा गासै मोनसे सिथिनो इम्प'र्ट खालाम।
TallyPrime-नि आफादनि हेल्प (help.tallysolutions.com) निफ्रायनि स्टेपफोर, 2026 नभेम्बर 5 आव नायफिन। रिलिजफोरनि गेजेराव मेनुफोर सोलायनो हायो; नोंथांनि TallyPrime रिलिजनि हेल्प नाय। Nivesh Sahayak आ Tally Solutions नि बागा नङा।
