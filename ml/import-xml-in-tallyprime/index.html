TallyPrime-ൽ XML ഫയൽ എങ്ങനെ ഇമ്പോർട്ട് ചെയ്യാം

TallyPrime-ന് XML ഫയലുകളിൽ നിന്ന് ഡാറ്റ വായിക്കാം (റിലീസ് 4.0 മുതൽ Excel-ൽ നിന്നും). ഈ സൈറ്റിൽ ഉണ്ടാക്കുന്ന ഫയലുകൾ XML ആണ്. ഇമ്പോർട്ട് ഒരു മിനിറ്റ് മതി, പക്ഷേ ക്രമം പ്രധാനമാണ്: ആദ്യം ലെഡ്ജറുകൾ, പിന്നെ വൗച്ചറുകൾ.

തുടങ്ങുംമുൻപ്

  • TallyPrime-ൽ കമ്പനിയുടെ ബാക്കപ്പ് എടുക്കുക. ഇമ്പോർട്ട് ഒറ്റയടിക്ക് എൻട്രികൾ ചേർക്കും; ബാക്കപ്പ് ഉണ്ടെങ്കിൽ തിരികെ പോകാം.
  • ശരിയായ കമ്പനി തുറക്കുക, അതിന്റെ സാമ്പത്തിക വർഷം വൗച്ചറുകളുടെ തീയതികളെ ഉൾക്കൊള്ളുന്നുണ്ടോ എന്ന് നോക്കുക.
  • ബിൽ-വൈസ് വിവരങ്ങൾക്ക് കമ്പനി ഫീച്ചറുകളിൽ (F11) ബിൽ-വൈസ് എൻട്രികൾ ഓണാക്കുക, പാർട്ടി ലെഡ്ജറുകളിൽ Maintain balances bill-by-bill ഓണായി വയ്ക്കുക.

ഘട്ടം 1: ലെഡ്ജറുകൾ (masters)

  1. Alt+O (Import) › Masters അമർത്തുക.
  2. File Path-ൽ ലെഡ്ജർ ഫയലിന്റെ ഫോൾഡറും പേരും നൽകുക, ഉദാഹരണത്തിന് Downloads-ലെ tally-masters-2026-11-05.xml.
  3. ആ പേരിൽ ഒരു ലെഡ്ജർ ഇതിനകം ഉണ്ടെങ്കിൽ Tally എന്ത് ചെയ്യണമെന്ന് തിരഞ്ഞെടുക്കുക: Combine opening balance, Ignore duplicates (നിങ്ങളുടേത് നിലനിർത്തി ഞങ്ങളുടേത് ഒഴിവാക്കും) അല്ലെങ്കിൽ Modify with new data (ഞങ്ങളുടേത് നിങ്ങളുടേതിനെ മാറ്റും). ഈ പാർട്ടികൾ നിങ്ങളുടെ Tally-യിൽ ശ്രദ്ധയോടെ ഉണ്ടാക്കിയിട്ടുണ്ടെങ്കിൽ Ignore duplicates തിരഞ്ഞെടുക്കുക.
  4. ബാക്കപ്പിന് Yes പറഞ്ഞ് Enter അമർത്തുക. എത്ര മാസ്റ്ററുകൾ ഉണ്ടാക്കി, മാറ്റി, അല്ലെങ്കിൽ ഒഴിവാക്കി എന്ന് Tally കാണിക്കും.

ഘട്ടം 2: വൗച്ചറുകൾ (transactions)

  1. Alt+O (Import) › Transactions അമർത്തുക.
  2. വൗച്ചർ ഫയലിന്റെ പാത്ത് നൽകുക (tally-vouchers-….xml), ബാക്കപ്പിന് Yes പറഞ്ഞ് Enter അമർത്തുക.
  3. ആ തീയതികളുടെ Day Book തുറന്ന് ചില വൗച്ചറുകൾ നിങ്ങളുടെ ബില്ലുകളുമായി ഒത്തുനോക്കുക.

Tally പിശക് കാണിച്ചാൽ

  • ലെഡ്ജർ ഇല്ല: ലെഡ്ജർ ഫയൽ ആദ്യം ഇമ്പോർട്ട് ചെയ്തില്ല, അല്ലെങ്കിൽ വൗച്ചറുകളിലെ ലെഡ്ജർ പേര് നിങ്ങളുടെ Tally-യിലേതിൽ നിന്ന് വ്യത്യസ്തമാണ്. "Ledger names in your Tally"-ൽ പേര് ശരിയാക്കി, രണ്ട് ഫയലും വീണ്ടും ഉണ്ടാക്കി, വീണ്ടും ഇമ്പോർട്ട് ചെയ്യുക.
  • വൗച്ചർ ടൈപ്പ് ഇല്ല: വൗച്ചറുകൾ Tally-യുടെ സ്വന്തം ടൈപ്പുകൾ ഉപയോഗിക്കുന്നു: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note, Journal. ആ ടൈപ്പുകൾ നിങ്ങളുടെ കമ്പനിയിൽ ആക്ടീവ് ആണോ എന്ന് നോക്കുക.
  • ആകെത്തുക പൊരുത്തപ്പെടുന്നില്ല: ഓരോ വൗച്ചറിലും ഡെബിറ്റുകൾ ക്രെഡിറ്റുകൾക്ക് തുല്യമായിരിക്കണം. ഇവിടെ ഉണ്ടാക്കുന്ന ഫയലുകൾ എപ്പോഴും ബാലൻസ് ആയിരിക്കും; കൈകൊണ്ട് എഡിറ്റ് ചെയ്ത Excel രജിസ്റ്ററിൽ മാത്രമേ ഇത് സംഭവിക്കൂ. ആ വരി ശരിയാക്കുക.
  • ഒരേ വൗച്ചറുകൾ രണ്ടുതവണ ഇമ്പോർട്ട് ചെയ്താൽ അവ രണ്ടുതവണ ഉണ്ടാകും. ഓരോ കാലയളവും ഒരു തവണ മാത്രം ഇമ്പോർട്ട് ചെയ്യുക.
