TallyPrime ನಲ್ಲಿ XML ಫೈಲ್ ಇಂಪೋರ್ಟ್ ಮಾಡುವುದು ಹೇಗೆ

TallyPrime XML ಫೈಲ್‌ಗಳಿಂದ (Release 4.0 ರಿಂದ Excel ನಿಂದಲೂ) ಡೇಟಾ ಓದಬಲ್ಲದು. ಈ ಸೈಟ್‌ನಲ್ಲಿ ಮಾಡುವ ಫೈಲ್‌ಗಳು XML. ಇಂಪೋರ್ಟ್‌ಗೆ ಒಂದು ನಿಮಿಷ ಸಾಕು, ಆದರೆ ಕ್ರಮ ಮುಖ್ಯ: ಮೊದಲು ಲೆಡ್ಜರ್‌ಗಳು, ನಂತರ ವೋಚರ್‌ಗಳು.

ಶುರುಮಾಡುವ ಮೊದಲು

  • TallyPrime ನಲ್ಲಿ ಕಂಪನಿಯ ಬ್ಯಾಕಪ್ ತೆಗೆದುಕೊಳ್ಳಿ. ಇಂಪೋರ್ಟ್ ದಾಖಲೆಗಳನ್ನು ಒಂದೇ ಬಾರಿ ಸೇರಿಸುತ್ತದೆ; ಬ್ಯಾಕಪ್ ಇದ್ದರೆ ಹಿಂದೆ ಹೋಗಬಹುದು.
  • ಸರಿಯಾದ ಕಂಪನಿಯನ್ನು ತೆರೆದು, ಅದರ ಆರ್ಥಿಕ ವರ್ಷ ವೋಚರ್‌ಗಳ ದಿನಾಂಕಗಳನ್ನು ಒಳಗೊಂಡಿದೆಯೇ ಎಂದು ನೋಡಿ.
  • ಬಿಲ್ ವಾರು ವಿವರಗಳಿಗೆ, ಕಂಪನಿ ಫೀಚರ್‌ಗಳಲ್ಲಿ (F11) bill-wise entries ಆನ್ ಮಾಡಿ, ಪಾರ್ಟಿ ಲೆಡ್ಜರ್‌ಗಳಿಗೆ Maintain balances bill-by-bill ಆನ್ ಇಡಿ.

ಹಂತ 1: ಲೆಡ್ಜರ್‌ಗಳು (ಮಾಸ್ಟರ್‌ಗಳು)

  1. Alt+O (Import) › Masters ಒತ್ತಿ.
  2. File Path ನಲ್ಲಿ, ಲೆಡ್ಜರ್‌ಗಳ ಫೈಲ್‌ನ ಫೋಲ್ಡರ್ ಮತ್ತು ಹೆಸರು ಕೊಡಿ, ಉದಾಹರಣೆಗೆ ಡೌನ್‌ಲೋಡ್ಸ್‌ನಲ್ಲಿರುವ tally-masters-2026-11-05.xml.
  3. ಅದೇ ಹೆಸರಿನ ಲೆಡ್ಜರ್ ಈಗಾಗಲೇ ಇದ್ದರೆ Tally ಏನು ಮಾಡಬೇಕೆಂದು ಆಯ್ಕೆಮಾಡಿ: Combine opening balance, Ignore duplicates (ನಿಮ್ಮದನ್ನು ಇಟ್ಟು, ನಮ್ಮದನ್ನು ಬಿಡು) ಅಥವಾ Modify with new data (ನಮ್ಮದು ನಿಮ್ಮದನ್ನು ಬದಲಿಸುತ್ತದೆ). ನಿಮ್ಮ Tally ಯಲ್ಲಿ ಈ ಪಾರ್ಟಿಗಳು ಈಗಾಗಲೇ ಜಾಗರೂಕತೆಯಿಂದ ಸೆಟಪ್ ಆಗಿದ್ದರೆ, Ignore duplicates ಆಯ್ಕೆಮಾಡಿ.
  4. ಬ್ಯಾಕಪ್ ಕೇಳಿದರೆ Yes ಹೇಳಿ, Enter ಒತ್ತಿ. ಎಷ್ಟು ಮಾಸ್ಟರ್‌ಗಳನ್ನು ರಚಿಸಲಾಯಿತು, ಬದಲಿಸಲಾಯಿತು, ಬಿಡಲಾಯಿತು ಎಂದು Tally ತೋರಿಸುತ್ತದೆ.

ಹಂತ 2: ವೋಚರ್‌ಗಳು (ಟ್ರಾನ್ಸಾಕ್ಷನ್‌ಗಳು)

  1. Alt+O (Import) › Transactions ಒತ್ತಿ.
  2. ವೋಚರ್‌ಗಳ ಫೈಲ್‌ನ ಪಾತ್ (tally-vouchers-….xml) ಕೊಟ್ಟು, ಬ್ಯಾಕಪ್ ಕೇಳಿದರೆ Yes ಹೇಳಿ, Enter ಒತ್ತಿ.
  3. ಆ ದಿನಾಂಕಗಳಿಗೆ Day Book ತೆರೆದು, ಕೆಲವು ವೋಚರ್‌ಗಳನ್ನು ನಿಮ್ಮ ಬಿಲ್‌ಗಳೊಂದಿಗೆ ಹೋಲಿಸಿ ನೋಡಿ.

Tally ದೋಷ ತೋರಿಸಿದರೆ

  • A ledger does not exist: ಲೆಡ್ಜರ್‌ಗಳ ಫೈಲ್ ಅನ್ನು ಮೊದಲು ಇಂಪೋರ್ಟ್ ಮಾಡಿಲ್ಲ, ಅಥವಾ ವೋಚರ್‌ಗಳಲ್ಲಿನ ಲೆಡ್ಜರ್ ಹೆಸರು ನಿಮ್ಮ Tally ಯಲ್ಲಿರುವುದಕ್ಕಿಂತ ಬೇರೆಯಾಗಿದೆ. "ನಿಮ್ಮ Tally ಯಲ್ಲಿನ ಲೆಡ್ಜರ್ ಹೆಸರುಗಳು" ನಲ್ಲಿ ಹೆಸರು ಸರಿಪಡಿಸಿ, ಎರಡೂ ಫೈಲ್‌ಗಳನ್ನು ಮತ್ತೆ ಮಾಡಿ, ಮತ್ತೆ ಇಂಪೋರ್ಟ್ ಮಾಡಿ.
  • A voucher type does not exist: ವೋಚರ್‌ಗಳು Tally ಯ ಸ್ವಂತ ವಿಧಗಳನ್ನು ಬಳಸುತ್ತವೆ: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note, Journal. ಆ ವಿಧಗಳು ನಿಮ್ಮ ಕಂಪನಿಯಲ್ಲಿ ಸಕ್ರಿಯವಾಗಿವೆಯೇ ಎಂದು ನೋಡಿ.
  • Totals do not match: ಪ್ರತಿ ವೋಚರ್‌ನ ಡೆಬಿಟ್‌ಗಳು ಅದರ ಕ್ರೆಡಿಟ್‌ಗಳಿಗೆ ಸಮನಾಗಿರಬೇಕು. ಇಲ್ಲಿ ಮಾಡುವ ಫೈಲ್‌ಗಳು ಯಾವಾಗಲೂ ಬ್ಯಾಲೆನ್ಸ್ ಆಗುತ್ತವೆ; ಕೈಯಾರೆ ಎಡಿಟ್ ಮಾಡಿದ Excel ರಿಜಿಸ್ಟರ್‌ನಲ್ಲಿ ಮಾತ್ರ ಹೀಗಾಗುತ್ತದೆ. ಆ ಸಾಲನ್ನು ಸರಿಪಡಿಸಿ.
  • ಅದೇ ವೋಚರ್‌ಗಳನ್ನು ಎರಡು ಬಾರಿ ಇಂಪೋರ್ಟ್ ಮಾಡಿದರೆ ಅವು ಎರಡು ಬಾರಿ ಸೃಷ್ಟಿಯಾಗುತ್ತವೆ. ಪ್ರತಿ ಅವಧಿಯನ್ನು ಒಮ್ಮೆ ಮಾತ್ರ ಇಂಪೋರ್ಟ್ ಮಾಡಿ.
