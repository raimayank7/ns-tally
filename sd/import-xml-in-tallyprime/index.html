TallyPrime ۾ XML فائل ڪيئن امپورٽ ڪجي

TallyPrime XML فائلن مان ڊيٽا پڙهي سگهي ٿو (۽ Release 4.0 کان Excel مان به). هن سائيٽ تي ٺهيل فائلون XML آهن. امپورٽ ۾ هڪ منٽ لڳي ٿو، پر ترتيب اهم آهي: پهرين ليجر، پوءِ واؤچر.

شروع ڪرڻ کان اڳ

  • TallyPrime ۾ ڪمپني جو بيڪ اپ وٺو. امپورٽ هڪ ئي ڀيرو انٽريون شامل ڪري ٿو؛ بيڪ اپ توهان کي واپس وڃڻ ڏئي ٿو.
  • صحيح ڪمپني کوليو، ۽ چيڪ ڪريو ته ان جو مالي سال واؤچرن جي تاريخن کي ڍڪي ٿو.
  • بل وار ڊيٽيل لاءِ، ڪمپني فيچرز (F11) ۾ بل وار انٽريون چالو ڪريو ۽ پارٽي ليجرن لاءِ Maintain balances bill-by-bill چالو رکو.

قدم 1: ليجر (ماسٽرز)

  1. Alt+O (Import) › Masters دٻايو.
  2. File Path ۾ ليجر فائل جو فولڊر ۽ نالو ڏيو، مثال طور Downloads ۾ tally-masters-2026-11-05.xml.
  3. چونڊيو ته ان نالي جو ليجر اڳ ۾ موجود هجي ته Tally ڇا ڪري: Combine opening balance، Ignore duplicates (توهان جو رکو، اسان جو ڇڏي ڏيو) يا Modify with new data (اسان جو توهان جي جڳهه وٺي). جيڪڏهن توهان جي Tally ۾ اهي پارٽيون اڳ ۾ ئي احتياط سان ٺهيل آهن ته Ignore duplicates چونڊيو.
  4. بيڪ اپ لاءِ Yes چئو، Enter دٻايو. Tally ڏيکاري ٿو ته ڪيترا ماسٽر ٺهيا، بدليا يا ڇڏيا ويا.

قدم 2: واؤچر (ٽرانزيڪشنز)

  1. Alt+O (Import) › Transactions دٻايو.
  2. واؤچر فائل جو پاٿ ڏيو (tally-vouchers-….xml)، بيڪ اپ لاءِ Yes چئو، Enter دٻايو.
  3. انهن تاريخن لاءِ Day Book کوليو ۽ ڪجهه واؤچر پنهنجن بلن سان ملايو.

جيڪڏهن Tally ايرر ٻڌائي

  • ليجر موجود ناهي: ليجر فائل پهرين امپورٽ نه ڪئي وئي، يا واؤچرن ۾ ليجر جو نالو توهان جي Tally وارو نالو نه آهي. "توهان جي Tally ۾ ليجر جا نالا" ۾ نالو درست ڪريو، ٻئي فائلون ٻيهر ٺاهيو، ٻيهر امپورٽ ڪريو.
  • واؤچر جو قسم موجود ناهي: واؤچر Tally جا پنهنجا قسم استعمال ڪن ٿا: Sales، Purchase، Receipt، Payment، Credit Note، Debit Note ۽ Journal. چيڪ ڪريو ته اهي قسم توهان جي ڪمپني ۾ ايڪٽو آهن.
  • ڪل نه ملن ٿا: هر واؤچر جا ڊيبٽ ان جي ڪريڊٽ جي برابر هجڻ گهرجن. هتي ٺهيل فائلون هميشه ملن ٿيون؛ اهو رڳو هٿ سان ايڊٽ ڪيل Excel رجسٽر سان ٿئي ٿو. اها قطار درست ڪريو.
  • ساڳيا واؤچر ٻه ڀيرا امپورٽ ڪرڻ سان اهي ٻه ڀيرا ٺهن ٿا. هر دور هڪ ڀيرو امپورٽ ڪريو.
