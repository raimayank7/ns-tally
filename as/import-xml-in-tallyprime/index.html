TallyPrime ত XML ফাইল কেনেকৈ ইম্প’ৰ্ট কৰিব

TallyPrime য়ে XML ফাইলৰ পৰা ডেটা পঢ়িব পাৰে (আৰু Release 4.0 ৰ পৰা Excel ৰ পৰাও)। এই ছাইটত বনোৱা ফাইলবোৰ XML। ইম্প’ৰ্টত এক মিনিট লাগে, কিন্তু ক্ৰমটো গুৰুত্বপূৰ্ণ: আগতে লেজাৰ, তাৰ পাছত ভাউচাৰ।

আৰম্ভ কৰাৰ আগতে

  • TallyPrime ত কোম্পানীৰ বেকআপ লওক। ইম্প’ৰ্টে এবাৰতে এণ্ট্ৰি যোগ কৰে; বেকআপ থাকিলে আগৰ অৱস্থালৈ উভতিব পাৰি।
  • সঠিক কোম্পানী খোলক, আৰু চাওক তাৰ বিত্তীয় বৰ্ষই ভাউচাৰৰ তাৰিখবোৰ সামৰে নে নাই।
  • বিল অনুসৰি তথ্যৰ বাবে কোম্পানীৰ ফিচাৰত (F11) বিল-ৱাইজ এণ্ট্ৰি চালু কৰক আৰু পাৰ্টী লেজাৰত Maintain balances bill-by-bill চালু ৰাখক।

ধাপ 1: লেজাৰ (মাষ্টাৰ)

  1. Alt+O (Import) › Masters টিপক।
  2. File Path ত লেজাৰ ফাইলৰ ফোল্ডাৰ আৰু নাম দিয়ক, যেনে Downloads ত tally-masters-2026-11-05.xml।
  3. সেই নামৰ লেজাৰ আগৰে পৰা থাকিলে Tally য়ে কি কৰিব বাছক: Combine opening balance, Ignore duplicates (আপোনাৰটো থাকিব, আমাৰটো বাদ) বা Modify with new data (আমাৰটোৱে আপোনাৰটো সলনি কৰিব)। আপোনাৰ Tally ত এই পাৰ্টীবোৰ যত্নসহকাৰে আগতেই বনোৱা থাকিলে Ignore duplicates বাছক।
  4. বেকআপৰ প্ৰশ্নত Yes কওক, Enter টিপক। Tally য়ে দেখুৱায় কিমানটা মাষ্টাৰ বনিল, সলনি হ’ল বা বাদ গ’ল।

ধাপ 2: ভাউচাৰ (ট্ৰেঞ্জেকচন)

  1. Alt+O (Import) › Transactions টিপক।
  2. ভাউচাৰ ফাইলৰ পাথ দিয়ক (tally-vouchers-….xml), বেকআপত Yes কওক, Enter টিপক।
  3. সেই তাৰিখবোৰৰ Day Book খোলক আৰু কেইটামান ভাউচাৰ আপোনাৰ বিলৰ লগত মিলাই চাওক।

Tally য়ে এৰৰ দেখুৱালে

  • লেজাৰ নাই: লেজাৰ ফাইল আগতে ইম্প’ৰ্ট হোৱা নাই, বা ভাউচাৰত লেজাৰৰ নাম আপোনাৰ Tally ৰ নামতকৈ বেলেগ। “আপোনাৰ Tally ত লেজাৰৰ নাম” ত নাম ঠিক কৰক, দুয়োটা ফাইল আকৌ বনাওক, আকৌ ইম্প’ৰ্ট কৰক।
  • ভাউচাৰৰ প্ৰকাৰ নাই: ভাউচাৰবোৰে Tally ৰ নিজৰ প্ৰকাৰ ব্যৱহাৰ কৰে: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note আৰু Journal। চাওক সেইবোৰ আপোনাৰ কোম্পানীত চালু আছে নেকি।
  • মুঠ নিমিলে: প্ৰতিটো ভাউচাৰৰ ডেবিট তাৰ ক্ৰেডিটৰ সমান হ’ব লাগিব। ইয়াত বনোৱা ফাইল সদায় বেলেঞ্চড থাকে; ই হয় কেৱল হাতেৰে এডিট কৰা Excel ৰেজিষ্টাৰত। সেই শাৰী ঠিক কৰক।
  • একেটা ভাউচাৰ দুবাৰ ইম্প’ৰ্ট কৰিলে দুবাৰ বনি যায়। প্ৰতিটো সময় এবাৰকৈ ইম্প’ৰ্ট কৰক।
