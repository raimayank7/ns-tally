TallyPrime ରେ XML ଫାଇଲ୍ କିପରି ଇମ୍ପୋର୍ଟ କରିବେ

TallyPrime XML ଫାଇଲ୍‌ରୁ ଡାଟା ପଢ଼ିପାରେ (ଏବଂ Release 4.0 ଠାରୁ Excel ରୁ ମଧ୍ୟ)। ଏହି ସାଇଟ୍‌ରେ ବନୁଥିବା ଫାଇଲ୍ XML। ଇମ୍ପୋର୍ଟରେ ଏକ ମିନିଟ୍ ଲାଗେ, କିନ୍ତୁ କ୍ରମ ଗୁରୁତ୍ୱପୂର୍ଣ୍ଣ: ପ୍ରଥମେ ଲେଜର୍, ତା’ପରେ ଭାଉଚର୍।

ଆରମ୍ଭ କରିବା ପୂର୍ବରୁ

  • TallyPrime ରେ କମ୍ପାନୀର ବ୍ୟାକଅପ୍ ନିଅନ୍ତୁ। ଇମ୍ପୋର୍ଟ ଥରକେ ଅନେକ ଏଣ୍ଟ୍ରି ଯୋଡ଼େ; ବ୍ୟାକଅପ୍ ଥିଲେ ପଛକୁ ଫେରିହେବ।
  • ଠିକ୍ କମ୍ପାନୀ ଖୋଲନ୍ତୁ, ଏବଂ ଏହାର ଆର୍ଥିକ ବର୍ଷ ଭାଉଚର୍‌ର ତାରିଖ ଘେରୁଛି କି ଦେଖନ୍ତୁ।
  • ବିଲ୍ ଅନୁସାରେ ବିବରଣୀ ପାଇଁ କମ୍ପାନୀ ଫିଚର୍ସ (F11) ରେ ବିଲ୍ ଅନୁସାରେ ଏଣ୍ଟ୍ରି ଚାଲୁ କରନ୍ତୁ ଏବଂ ପାର୍ଟି ଲେଜର୍ ପାଇଁ Maintain balances bill-by-bill ଚାଲୁ ରଖନ୍ତୁ।

ଷ୍ଟେପ୍ 1: ଲେଜର୍ (ମାଷ୍ଟର୍)

  1. Alt+O (Import) › Masters ଦବାନ୍ତୁ।
  2. File Path ରେ ଲେଜର୍ ଫାଇଲ୍‌ର ଫୋଲ୍ଡର୍ ଓ ନାମ ଦିଅନ୍ତୁ, ଯେପରି Downloads ରେ ଥିବା tally-masters-2026-11-05.xml।
  3. ସେହି ନାମର ଲେଜର୍ ଆଗରୁ ଥିଲେ Tally କ’ଣ କରିବ ବାଛନ୍ତୁ: Combine opening balance, Ignore duplicates (ଆପଣଙ୍କଟି ରଖ, ଆମଟି ଛାଡ଼) ବା Modify with new data (ଆମଟି ଆପଣଙ୍କଟିକୁ ବଦଳାଏ)। ଆପଣଙ୍କ Tally ରେ ଏହି ପାର୍ଟି ଆଗରୁ ଯତ୍ନ ସହ ସେଟ୍ ହୋଇଥିଲେ Ignore duplicates ବାଛନ୍ତୁ।
  4. ବ୍ୟାକଅପ୍‌କୁ Yes କୁହନ୍ତୁ, Enter ଦବାନ୍ତୁ। କେତୋଟି ମାଷ୍ଟର୍ ବନିଲା, ବଦଳିଲା ବା ଛଡ଼ାଗଲା Tally ଦେଖାଏ।

ଷ୍ଟେପ୍ 2: ଭାଉଚର୍ (ଟ୍ରାଞ୍ଜାକ୍ସନ୍)

  1. Alt+O (Import) › Transactions ଦବାନ୍ତୁ।
  2. ଭାଉଚର୍ ଫାଇଲ୍‌ର ପାଥ୍ ଦିଅନ୍ତୁ (tally-vouchers-….xml), ବ୍ୟାକଅପ୍‌କୁ Yes କୁହନ୍ତୁ, Enter ଦବାନ୍ତୁ।
  3. ସେହି ତାରିଖ ପାଇଁ Day Book ଖୋଲନ୍ତୁ ଏବଂ କିଛି ଭାଉଚର୍ ଆପଣଙ୍କ ବିଲ୍ ସହ ମିଳାଇ ଦେଖନ୍ତୁ।

  • ଲେଜର୍ ନାହିଁ: ଲେଜର୍ ଫାଇଲ୍ ପ୍ରଥମେ ଇମ୍ପୋର୍ଟ ହୋଇନଥିଲା, ବା ଭାଉଚର୍‌ରେ ଥିବା ଲେଜର୍ ନାମ ଆପଣଙ୍କ Tally ର ନାମଠାରୁ ଅଲଗା। "ଆପଣଙ୍କ Tally ର ଲେଜର୍ ନାମ" ରେ ନାମ ଠିକ୍ କରନ୍ତୁ, ଦୁଇ ଫାଇଲ୍ ପୁଣି ବନାନ୍ତୁ, ପୁଣି ଇମ୍ପୋର୍ଟ କରନ୍ତୁ।
  • ଭାଉଚର୍ ପ୍ରକାର ନାହିଁ: ଭାଉଚର୍ Tally ର ନିଜ ପ୍ରକାର ବ୍ୟବହାର କରେ: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note ଓ Journal। ସେହି ପ୍ରକାର ଆପଣଙ୍କ କମ୍ପାନୀରେ ସକ୍ରିୟ କି ଦେଖନ୍ତୁ।
  • ମୋଟ ମିଳୁନାହିଁ: ପ୍ରତ୍ୟେକ ଭାଉଚର୍‌ର ଡେବିଟ୍ ତାର କ୍ରେଡିଟ୍ ସହ ସମାନ ହେବା ଦରକାର। ଏଠାରେ ବନୁଥିବା ଫାଇଲ୍ ସବୁବେଳେ ମିଳେ; ଏହା କେବଳ ହାତରେ ବଦଳାଯାଇଥିବା Excel ରେଜିଷ୍ଟରରେ ହୁଏ। ସେହି ଧାଡ଼ି ଠିକ୍ କରନ୍ତୁ।
  • ସେହି ଭାଉଚର୍ ଦୁଇଥର ଇମ୍ପୋର୍ଟ କଲେ ଦୁଇଥର ବନେ। ପ୍ରତ୍ୟେକ ଅବଧି ଥରେ ମାତ୍ର ଇମ୍ପୋର୍ଟ କରନ୍ତୁ।
