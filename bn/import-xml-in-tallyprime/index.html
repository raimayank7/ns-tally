TallyPrime-এ XML ফাইল কীভাবে ইমপোর্ট করবেন

TallyPrime XML ফাইল থেকে ডেটা পড়তে পারে (আর Release 4.0 থেকে Excel থেকেও)। এই সাইটে বানানো ফাইলগুলো XML। ইমপোর্টে এক মিনিট লাগে, কিন্তু ক্রমটা জরুরি: আগে লেজার, তারপর ভাউচার।

শুরুর আগে

  • TallyPrime-এ কোম্পানির ব্যাকআপ নিন। ইমপোর্ট একবারে এন্ট্রি যোগ করে; ব্যাকআপ থাকলে আগের অবস্থায় ফেরা যায়।
  • ঠিক কোম্পানি খুলুন, আর দেখুন তার অর্থবর্ষ ভাউচারের তারিখগুলো ধরে কিনা।
  • বিল ধরে ধরে তথ্যের জন্য কোম্পানির ফিচারে (F11) বিল-ওয়াইজ এন্ট্রি চালু করুন আর পার্টি লেজারে Maintain balances bill-by-bill চালু রাখুন।

ধাপ 1: লেজার (মাস্টার)

  1. Alt+O (Import) › Masters চাপুন।
  2. File Path-এ লেজার ফাইলের ফোল্ডার আর নাম দিন, যেমন Downloads-এ tally-masters-2026-11-05.xml।
  3. ওই নামের লেজার আগে থেকে থাকলে Tally কী করবে বেছে নিন: Combine opening balance, Ignore duplicates (আপনারটা থাকবে, আমাদেরটা বাদ) বা Modify with new data (আমাদেরটা আপনারটা বদলে দেবে)। আপনার Tally-তে এই পার্টিগুলো যত্ন করে আগেই বানানো থাকলে Ignore duplicates বেছে নিন।
  4. ব্যাকআপের প্রশ্নে Yes বলুন, Enter চাপুন। Tally দেখায় কতগুলো মাস্টার তৈরি, বদল বা বাদ গেল।

ধাপ 2: ভাউচার (ট্রানজ্যাকশন)

  1. Alt+O (Import) › Transactions চাপুন।
  2. ভাউচার ফাইলের পাথ দিন (tally-vouchers-….xml), ব্যাকআপে Yes বলুন, Enter চাপুন।
  3. ওই তারিখগুলোর Day Book খুলুন আর কয়েকটা ভাউচার আপনার বিলের সঙ্গে মিলিয়ে দেখুন।

Tally এরর দেখালে

  • লেজার নেই: লেজার ফাইল আগে ইমপোর্ট হয়নি, বা ভাউচারে লেজারের নাম আপনার Tally-র নামের থেকে আলাদা। “আপনার Tally-তে লেজারের নাম”-এ নামটা ঠিক করুন, দুটো ফাইল আবার বানান, আবার ইমপোর্ট করুন।
  • ভাউচারের ধরন নেই: ভাউচারগুলো Tally-র নিজের ধরন ব্যবহার করে: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note আর Journal। দেখুন সেগুলো আপনার কোম্পানিতে চালু আছে কিনা।
  • মোট মিলছে না: প্রতিটা ভাউচারের ডেবিট তার ক্রেডিটের সমান হতে হবে। এখানে বানানো ফাইল সবসময় ব্যালেন্সড থাকে; এটা হয় শুধু হাতে এডিট করা Excel রেজিস্টারে। ওই সারি ঠিক করুন।
  • একই ভাউচার দুবার ইমপোর্ট করলে দুবার তৈরি হয়। প্রতিটা সময় একবারই ইমপোর্ট করুন।
