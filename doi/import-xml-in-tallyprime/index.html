TallyPrime च XML फ़ाइल किंञा इंपोर्ट करनी ऐ

TallyPrime XML फ़ाइलें थमां डेटा पढ़ी सकदा ऐ (ते Release 4.0 थमां Excel थमां बी)। इस साइट उप्पर बनदियां फ़ाइलां XML न। इंपोर्ट च इक मिंट लगदा ऐ, पर क्रम जरूरी ऐ: पैहलें लेजर, फ'र वाउचर।

शुरू करने कोला पैहलें

  • TallyPrime च कंपनी दा बैकअप लैओ। इंपोर्ट इक्की बारी च एंट्रियां जोड़दा ऐ; बैकअप होऐ तां पिच्छें जाई सकदे ओ।
  • ठीक कंपनी खोह्‌लो, ते जांचो के उसदा फ़ाइनेंशियल ईयर वाउचरें दी तरीकें गी कवर करदा ऐ।
  • बिल मताबक जानकारी आस्तै कंपनी दे फ़ीचरें (F11) च bill-wise entries चालू करो ते पार्टी लेजरें आस्तै Maintain balances bill-by-bill चालू रक्खो।

कदम 1: लेजर (मास्टर)

  1. Alt+O (Import) › Masters दबाओ।
  2. File Path च फोल्डर ते लेजर फ़ाइल दा नां देओ, जिय्यां Downloads च tally-masters-2026-11-05.xml।
  3. उस नां दा लेजर पैहलें थमां होऐ तां Tally गी केह् करना ऐ ओह् चुनो: Combine opening balance, Ignore duplicates (तुंदा रक्खो, साढ़ा छोड़ो) जां Modify with new data (साढ़ा तुंदे दी जगह लैऐ)। तुंदे Tally च एह् पार्टियां सावधानी कन्नै पैहलें थमां बनी दियां होन तां Ignore duplicates चुनो।
  4. बैकअप आस्तै Yes आखो, Enter दबाओ। Tally दस्सदा ऐ कितने मास्टर बने, बदले जां छोड़े गे।

कदम 2: वाउचर (ट्रांज़ैक्शन)

  1. Alt+O (Import) › Transactions दबाओ।
  2. वाउचर फ़ाइल दा पाथ देओ (tally-vouchers-….xml), बैकअप आस्तै Yes आखो, Enter दबाओ।
  3. उनें तरीकें आस्तै Day Book खोह्‌लो ते किश वाउचर अपने बिलें कन्नै मलाइयै दिक्खो।

Tally एरर दस्सै तां

  • लेजर मौजूद नेईं ऐ: लेजर फ़ाइल पैहलें इंपोर्ट नेईं होई, जां वाउचरें च लेजर दा नां तुंदे Tally दे नां शा बक्खरा ऐ। "तुंदे Tally च लेजरें दे नां" च नां ठीक करो, दोऐ फ़ाइलां फ'र बनाओ, फ'र इंपोर्ट करो।
  • वाउचर किस्म मौजूद नेईं ऐ: वाउचर Tally दी अपनी किस्में बरतदे न: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note ते Journal। जांचो के तुंदी कंपनी च एह् किस्में चालू न।
  • जोड़ नेईं मलदा: हर वाउचर दे डेबिट उसदे क्रेडिट दे बराबर होने चाहिदे। इत्थें बनी दियां फ़ाइलां हमेशा मलदियां न; एह् सिर्फ़ हत्थें बदले दे Excel रजिस्टर कन्नै होंदा ऐ। ओह् लैन ठीक करो।
  • इक्कै वाउचर दो बारी इंपोर्ट करो तां ओह् दो बारी बनदे न। हर अरसा इक्की बारी गै इंपोर्ट करो।
