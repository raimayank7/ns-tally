TallyPrime-मध्ये XML फ़ाइलं कथम् इम्पोर्ट् करणीया

TallyPrime XML फ़ाइलतः डेटा पठितुं शक्नोति (Release 4.0 तः Excel तः अपि)। अस्मिन् जालस्थले रचिताः फ़ाइलाः XML सन्ति। इम्पोर्ट् एकां निमेषं गृह्णाति, किन्तु क्रमः महत्त्वपूर्णः: प्रथमं लेजर्स्, ततः वाउचर्स्।

आरम्भात् पूर्वम्

  • TallyPrime-मध्ये कम्पन्याः बैकअप् गृह्णातु। इम्पोर्ट् एकदा प्रविष्टीः योजयति; बैकअप् पुनः गन्तुम् अनुमन्यते।
  • समीचीनां कम्पनीम् उद्घाटयतु, तस्याः वित्तीय-वर्षं वाउचर्-दिनाङ्कान् आवृणोति इति परीक्षतु च।
  • बिल-अनुसारि-विवरणस्य कृते कम्पनी-फ़ीचर्स् (F11) मध्ये बिल-अनुसारि-प्रविष्टीः सक्रियाः करोतु पार्टी-लेजरेषु च Maintain balances bill-by-bill सक्रियं रक्षतु।

सोपानम् 1: लेजर्स् (मास्टर्स्)

  1. Alt+O (Import) › Masters नुदतु।
  2. File Path मध्ये लेजर-फ़ाइलस्य फ़ोल्डरं नाम च ददातु, यथा Downloads-मध्ये tally-masters-2026-11-05.xml।
  3. तन्नाम्ना लेजर् पूर्वमेव विद्यते चेत् Tally किं करोतु इति चिनोतु: Combine opening balance, Ignore duplicates (भवतः रक्षतु, अस्माकं त्यजतु) अथवा Modify with new data (अस्माकं भवतः स्थाने)। भवतः Tally-मध्ये एताः पार्ट्यः पूर्वमेव सावधानतया स्थापिताः चेत् Ignore duplicates चिनोतु।
  4. बैकअप्-कृते Yes वदतु, Enter नुदतु। Tally दर्शयति कति मास्टर्स् रचिताः परिवर्तिताः उपेक्षिताः वा।

सोपानम् 2: वाउचर्स् (ट्रांजैक्शन्स्)

  1. Alt+O (Import) › Transactions नुदतु।
  2. वाउचर्-फ़ाइलस्य पथं ददातु (tally-vouchers-….xml), बैकअप्-कृते Yes वदतु, Enter नुदतु।
  3. तेषां दिनाङ्कानां कृते Day Book उद्घाटयतु कतिचित् वाउचर्स् स्वबिलैः सह तुलयतु च।

Tally दोषान् वदति चेत्

  • लेजर् न विद्यते: लेजर्-फ़ाइल प्रथमं न इम्पोर्ट्ता, अथवा वाउचर्-मध्ये लेजर्-नाम भवतः Tally-नाम्नः भिन्नम्। "भवतः Tally-मध्ये लेजर-नामानि" मध्ये नाम संशोधयतु, उभे फ़ाइले पुनः रचयतु, पुनः इम्पोर्ट् करोतु।
  • वाउचर्-प्रकारः न विद्यते: वाउचराः Tally-स्य स्वीय-प्रकारान् प्रयुञ्जन्ति: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note तथा Journal। एते प्रकाराः भवतः कम्पन्यां सक्रियाः सन्ति इति परीक्षतु।
  • कुल-राशयः न मिलन्ति: प्रत्येकस्य वाउचर्-स्य डेबिट्-नि तस्य क्रेडिट्-सदृशानि भवेयुः। अत्र रचिताः फ़ाइलाः सदा मिलन्ति; एतत् केवलं हस्तेन सम्पादिते Excel रजिस्टर्-मध्ये भवति। तां पङ्क्तिं संशोधयतु।
  • समानानि वाउचर्स् द्विवारम् इम्पोर्ट् चेत् द्विवारं रच्यन्ते। प्रत्येकम् अवधिम् एकवारम् इम्पोर्ट् करोतु।
