TallyPrime માં XML ફાઇલ કેવી રીતે ઇમ્પોર્ટ કરવી

TallyPrime XML ફાઇલમાંથી ડેટા વાંચી શકે છે (અને Release 4.0 થી Excel માંથી પણ). આ સાઇટ પર બનતી ફાઇલો XML છે. ઇમ્પોર્ટમાં એક મિનિટ લાગે છે, પણ ક્રમ મહત્ત્વનો છે: પહેલાં લેજર, પછી વાઉચર.

શરૂ કરતાં પહેલાં

  • TallyPrime માં કંપનીનો બેકઅપ લો. ઇમ્પોર્ટ એકસાથે એન્ટ્રી ઉમેરે છે; બેકઅપ હોય તો પાછા જઈ શકાય.
  • સાચી કંપની ખોલો, અને તપાસો કે તેનું ફાઇનાન્શિયલ યર વાઉચરની તારીખો આવરી લે છે.
  • બિલ પ્રમાણે વિગતો માટે કંપનીના ફીચરમાં (F11) bill-wise entries ચાલુ કરો અને પાર્ટી લેજર માટે Maintain balances bill-by-bill ચાલુ રાખો.

સ્ટેપ 1: લેજર (માસ્ટર)

  1. Alt+O (Import) › Masters દબાવો.
  2. File Path માં ફોલ્ડર અને લેજર ફાઇલનું નામ આપો, જેમ કે Downloads માં tally-masters-2026-11-05.xml.
  3. તે નામનું લેજર પહેલેથી હોય ત્યારે Tally શું કરે તે પસંદ કરો: Combine opening balance, Ignore duplicates (તમારું રાખો, અમારું છોડો) અથવા Modify with new data (અમારું તમારાને બદલે). તમારા Tally માં આ પાર્ટીઓ કાળજીથી પહેલેથી બનેલી હોય તો Ignore duplicates પસંદ કરો.
  4. બેકઅપ માટે Yes કહો, Enter દબાવો. Tally બતાવે છે કે કેટલા માસ્ટર બન્યા, બદલાયા કે છોડાયા.

સ્ટેપ 2: વાઉચર (ટ્રાન્ઝેક્શન)

  1. Alt+O (Import) › Transactions દબાવો.
  2. વાઉચર ફાઇલનો પાથ આપો (tally-vouchers-….xml), બેકઅપ માટે Yes કહો, Enter દબાવો.
  3. તે તારીખો માટે Day Book ખોલો અને થોડાં વાઉચર તમારાં બિલ સાથે સરખાવો.

Tally એરર બતાવે તો

  • લેજર અસ્તિત્વમાં નથી: લેજર ફાઇલ પહેલાં ઇમ્પોર્ટ થઈ નથી, અથવા વાઉચરમાંનું લેજરનું નામ તમારા Tally ના નામથી અલગ છે. "તમારા Tally માં લેજરનાં નામ" માં નામ સુધારો, બંને ફાઇલ ફરી બનાવો, ફરી ઇમ્પોર્ટ કરો.
  • વાઉચર પ્રકાર અસ્તિત્વમાં નથી: વાઉચર Tally ના પોતાના પ્રકાર વાપરે છે: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note અને Journal. તમારી કંપનીમાં આ પ્રકાર ચાલુ છે કે નહીં તે તપાસો.
  • કુલ રકમ મળતી નથી: દરેક વાઉચરના ડેબિટ તેના ક્રેડિટ બરાબર હોવા જોઈએ. અહીં બનેલી ફાઇલો હંમેશાં મળે છે; આવું ફક્ત હાથે ફેરફાર કરેલા Excel રજિસ્ટરમાં થાય છે. તે લાઇન સુધારો.
  • એ જ વાઉચર બે વાર ઇમ્પોર્ટ કરો તો તે બે વાર બને છે. દરેક સમયગાળો એક જ વાર ઇમ્પોર્ટ કરો.
