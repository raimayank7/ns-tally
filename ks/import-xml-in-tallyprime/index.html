TallyPrime منٛز XML فایِل کِتھ کر امپورٹ کرُن

TallyPrime ہیکہِ XML فایِلن پیٹھٕ ڈیٹا پرتھ (تہٕ ریلیز 4.0 پیٹھٕ Excel پیٹھٕ تہِ)۔ ییٹھ بنٲوَنہٕ آمتۍ فایِلہٕ چھِ XML۔ امپورٹس لگان اکھ منٹ، مگر ترتیب چھ اہم: پؠٹھمس لیجر، پتہٕ واؤچر۔

شروٗع کرنہٕ برونہہ

  • TallyPrime منٛز کمپنی ہند بیک اَپ ہیوُو۔ امپورٹ چھُ اکی ساعتہٕ اندراج جوڑان؛ بیک اَپ آسنہٕ پیٹھ ہیکو واپس گژھتھ۔
  • صحیح کمپنی یَلہٕ کٔرِو، تہٕ وچھِو زِ تَمہِ ہند مالی ؤریہ چھُ واؤچرن ہندین تٲریخن شامل کران۔
  • بِل وائز تفصیلن باپتھ کمپنی فیچرس (F11) منٛز بِل وائز اندراج آن کٔرِو تہٕ پارٹی لیجرن باپتھ Maintain balances bill-by-bill آن تھٲوِو۔

قدم 1: لیجر (masters)

  1. Alt+O (Import) › Masters دبٲوِو۔
  2. File Path منٛز لیجر فایِلک فولڈر تہٕ ناو دِیو، مثلاً Downloads منٛز tally-masters-2026-11-05.xml۔
  3. ییلہِ تمے ناومچ لیجر پیٚوٹھ آسِ تیلہِ ژارِو Tally کیا کرِ: Combine opening balance، Ignore duplicates (تُہٕنزِ تھاوِ، اَسہِ ہند چھوڑِ) یا Modify with new data (اَسہِ ہند تُہٕنزِ بدلہ ہیوِ)۔ اگر تُہٕنزِ Tally منٛز چھِ یم پارٹی احتیاطہٕ سٕتۍ بنٲوَنہٕ آمتۍ، تیلہِ ژارِو Ignore duplicates۔
  4. بیک اَپس باپتھ Yes وَنِو، Enter دبٲوِو۔ Tally چھُ ؤنان کتنہِ masters بنیومت، بدلیومت یا چھوڑنہٕ آمتۍ۔

قدم 2: واؤچر (transactions)

  1. Alt+O (Import) › Transactions دبٲوِو۔
  2. واؤچر فایِلُک راستہ دِیو (tally-vouchers-….xml)، بیک اَپس باپتھ Yes وَنِو، Enter دبٲوِو۔
  3. تمن تٲریخن ہند Day Book یَلہٕ کٔرِو تہٕ کینژھ واؤچر پانَن بلن سٕتۍ مٕلٲوِو۔

اگر Tally ایرر ؤنِ

  • لیجر موجود چھُ نہٕ: لیجر فایِل پؠٹھمس امپورٹ نہٕ گومت، یا واؤچرن منٛز لیجرُک ناو چھُ تُہٕنزِ Tally ہندس ناومس کھوتہٕ مختلف۔ "Ledger names in your Tally" منٛز ناو ٹھیک کٔرِو، ژوویی فایِلہٕ دوبارہ بنٲوِو، دوبارہ امپورٹ کٔرِو۔
  • واؤچر ٹائپ موجود چھُ نہٕ: واؤچر چھِ Tally ہندین پانَنین قسمن ورتاوان: Sales، Purchase، Receipt، Payment، Credit Note، Debit Note تہٕ Journal۔ وچھِو زِ تِم قسمہٕ چھِ تُہٕنزِ کمپنی منٛز فعال۔
  • ٹوٹل چھِ نہٕ مَلان: ہر واؤچرُک ڈیبٹ گژھِ تَمہِ ہندس کریڈٹس برابر آسن۔ ییٹھ بنٲوَنہٕ آمتۍ فایِلہٕ چھِ ہمیشہ بیلنس؛ یہِ چھُ صرف ہاتھن سٕتۍ ایڈٹ کرنہٕ آمتس Excel رجسٹرس منٛز گژھان۔ سۄ قطار ٹھیک کٔرِو۔
  • یمے واؤچر ژٕ کرٕتہِ امپورٹ کرنہٕ پیٹھ چھِ سۄ ژٕ کرٕتہِ بنان۔ ہر مدت امپورٹ کٔرِو صرف اکھ کرٕتہِ۔
