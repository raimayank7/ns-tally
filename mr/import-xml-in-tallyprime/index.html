TallyPrime मध्ये XML फाइल कशी इम्पोर्ट करायची

TallyPrime XML फाइलमधून डेटा वाचू शकते (आणि Release 4.0 पासून Excel मधूनही). या साइटवर बनणाऱ्या फाइल XML असतात. इम्पोर्टला एक मिनिट लागतो, पण क्रम महत्त्वाचा आहे: आधी लेजर, मग व्हाउचर.

सुरू करण्यापूर्वी

  • TallyPrime मध्ये कंपनीचा बॅकअप घ्या. इम्पोर्ट एकदम अनेक एन्ट्री जोडते; बॅकअप असेल तर मागे जाता येते.
  • योग्य कंपनी उघडा, आणि तिचे आर्थिक वर्ष व्हाउचरच्या तारखा कव्हर करते का ते तपासा.
  • बिलानुसार तपशीलासाठी कंपनी फीचर्समध्ये (F11) बिलानुसार एन्ट्री चालू करा आणि पार्टी लेजरसाठी Maintain balances bill-by-bill चालू ठेवा.

पायरी 1: लेजर (मास्टर)

  1. Alt+O (Import) › Masters दाबा.
  2. File Path मध्ये लेजर फाइलचे फोल्डर आणि नाव द्या, उदा. Downloads मधील tally-masters-2026-11-05.xml.
  3. त्याच नावाचा लेजर आधीपासून असेल तर Tally ने काय करावे ते निवडा: Combine opening balance, Ignore duplicates (तुमचा ठेवा, आमचा सोडा) किंवा Modify with new data (आमचा तुमच्याऐवजी येतो). तुमच्या Tally मध्ये या पार्टी आधीच काळजीपूर्वक सेट केल्या असतील तर Ignore duplicates निवडा.
  4. बॅकअपला Yes म्हणा, Enter दाबा. किती मास्टर तयार झाले, बदलले किंवा सोडले ते Tally दाखवते.

पायरी 2: व्हाउचर (ट्रान्झॅक्शन)

  1. Alt+O (Import) › Transactions दाबा.
  2. व्हाउचर फाइलचा पाथ द्या (tally-vouchers-….xml), बॅकअपला Yes म्हणा, Enter दाबा.
  3. त्या तारखांसाठी Day Book उघडा आणि काही व्हाउचर तुमच्या बिलांशी ताडून पाहा.

Tally ने एरर दाखवले तर

  • लेजर अस्तित्वात नाही: लेजर फाइल आधी इम्पोर्ट केली नव्हती, किंवा व्हाउचरमधील लेजरचे नाव तुमच्या Tally मधील नावापेक्षा वेगळे आहे. "तुमच्या Tally मधील लेजरची नावे" मध्ये नाव दुरुस्त करा, दोन्ही फाइल पुन्हा बनवा, पुन्हा इम्पोर्ट करा.
  • व्हाउचर प्रकार अस्तित्वात नाही: व्हाउचर Tally चे स्वतःचे प्रकार वापरतात: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note आणि Journal. ते प्रकार तुमच्या कंपनीत चालू आहेत का ते तपासा.
  • एकूण जुळत नाहीत: प्रत्येक व्हाउचरचे डेबिट त्याच्या क्रेडिटएवढे असले पाहिजेत. इथे बनलेल्या फाइल नेहमी जुळतात; हे फक्त हाताने बदललेल्या Excel रजिस्टरमध्येच होते. ती ओळ दुरुस्त करा.
  • तीच व्हाउचर दोनदा इम्पोर्ट केली तर ती दोनदा तयार होतात. प्रत्येक कालावधी एकदाच इम्पोर्ट करा.
