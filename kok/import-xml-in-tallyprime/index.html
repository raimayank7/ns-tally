TallyPrime त XML फायल कशी इम्पोर्ट करची

TallyPrime XML फायलींतल्यान डेटा वाचूंक शकता (आनी Release 4.0 पसून Excel वयल्यानूय). ह्या साइटार जावपी फायली XML आसात. इम्पोर्टाक एक मिनीट लागता, पूण क्रम म्हत्वाचो: आदीं लेजर, मागीर व्हावचर.

सुरू करचे आदीं

  • TallyPrime त कंपनीचो बॅकअप घेयात. इम्पोर्ट एकाच वेळार एंट्री जोडटा; बॅकअप आसल्यार फाटीं वचूंक येता.
  • बरी कंपनी उगडात, आनी तिजें फायनान्शियल इयर व्हावचरांच्या तारखांक पुरो पडटा तें तपासात.
  • बिला प्रमाण म्हायतीखातीर कंपनीच्या फीचरांनी (F11) bill-wise entries चालू करात आनी पार्टी लेजरांखातीर Maintain balances bill-by-bill चालू दवरात.

पायरी 1: लेजर (मास्टर)

  1. Alt+O (Import) › Masters दाबात.
  2. File Path त फोल्डर आनी लेजर फायलीचें नांव दियात, देखीक Downloads त tally-masters-2026-11-05.xml.
  3. त्या नांवाचें लेजर आदींच आसल्यार Tally नी कितें करचें तें वेंचून काढात: Combine opening balance, Ignore duplicates (तुमचें दवरात, आमचें सोडात) वा Modify with new data (आमचें तुमच्या जाग्यार येता). तुमच्या Tally त ह्यो पार्टी जतनायेन आदींच केल्ल्यो आसल्यार Ignore duplicates वेंचून काढात.
  4. बॅकअपाखातीर Yes म्हणात, Enter दाबात. Tally दाखयता कितले मास्टर तयार जाले, बदलले वा सोडले.

पायरी 2: व्हावचर (ट्रान्झॅक्शन)

  1. Alt+O (Import) › Transactions दाबात.
  2. व्हावचर फायलीचो पाथ दियात (tally-vouchers-….xml), बॅकअपाखातीर Yes म्हणात, Enter दाबात.
  3. त्या तारखां खातीर Day Book उगडात आनी कांय व्हावचर तुमच्या बिलांकडेन तपासात.

Tally नी एरर दाखयल्यार

  • लेजर नात: लेजर फायल आदीं इम्पोर्ट केल्ली ना, वा व्हावचरांतल्या लेजराचें नांव तुमच्या Tally तल्या नांवा परस वेगळें आसा. "तुमच्या Tally तल्या लेजरांचीं नांवां" त नांव नीट करात, दोनूय फायली परत करात, परत इम्पोर्ट करात.
  • व्हावचर प्रकार नात: व्हावचर Tally चेच प्रकार वापरतात: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note आनी Journal. तुमच्या कंपनींत हे प्रकार चालू आसात काय तें तपासात.
  • एकूण जुळना: दरेक व्हावचराचे डेबिट ताच्या क्रेडिटा इतले जाय. हांगा केल्ल्यो फायली सदांच जुळटात; अशें फकत हातान बदल केल्ल्या Excel रजिस्टराचे बाबतींत जाता. ती वळ नीट करात.
  • तेच व्हावचर दोन फावटी इम्पोर्ट केल्यार तीं दोन फावटी तयार जातात. दरेक कालावधी एकदांच इम्पोर्ट करात.
