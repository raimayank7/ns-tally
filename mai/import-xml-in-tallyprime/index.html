TallyPrime मे XML फ़ाइल कोना इम्पोर्ट करी

TallyPrime XML फ़ाइल सँ डेटा पढ़ि सकैत अछि (आ Release 4.0 सँ Excel सँ सेहो)। एहि साइट पर बनल फ़ाइल XML अछि। इम्पोर्ट मे एक मिनट लगैत अछि, मुदा क्रम जरूरी अछि: पहिने लेजर, तखन वाउचर।

शुरू करए सँ पहिने

  • TallyPrime मे कंपनीक बैकअप लिअ। इम्पोर्ट एक बेर मे एंट्री जोड़ि दैत अछि; बैकअप सँ पाछाँ जा सकैत छी।
  • सही कंपनी खोलू, आ देखू जे ओकर वित्त वर्ष वाउचरक तारीख केँ समेटैत अछि।
  • बिल-वार जानकारी लेल कंपनी फीचर (F11) मे बिल-वार एंट्री चालू करू आ पार्टी लेजर पर Maintain balances bill-by-bill चालू राखू।

स्टेप 1: लेजर (मास्टर)

  1. Alt+O (Import) › Masters दबाउ।
  2. File Path मे लेजर फ़ाइलक फोल्डर आ नाम दिअ, जेना Downloads मे tally-masters-2026-11-05.xml।
  3. चुनू जे ओहि नामक लेजर पहिनहि अछि तँ Tally की करए: Combine opening balance, Ignore duplicates (अहाँक राखू, हमर छोड़ू) वा Modify with new data (हमर अहाँक केँ बदलि दिअए)। अहाँक Tally मे ई पार्टी पहिनहि सावधानी सँ बनल अछि तँ Ignore duplicates चुनू।
  4. बैकअप पर Yes कहू, Enter दबाउ। Tally देखबैत अछि कतेक मास्टर बनल, बदलल वा छोड़ल गेल।

स्टेप 2: वाउचर (ट्रांजैक्शन)

  1. Alt+O (Import) › Transactions दबाउ।
  2. वाउचर फ़ाइलक पाथ दिअ (tally-vouchers-….xml), बैकअप पर Yes कहू, Enter दबाउ।
  3. ओहि तारीखक Day Book खोलू आ किछु वाउचर अपन बिल सँ मिलाउ।

Tally एरर बताबए तँ

  • लेजर अस्तित्व मे नहि अछि: लेजर फ़ाइल पहिने इम्पोर्ट नहि भेल, वा वाउचर मे लेजरक नाम अहाँक Tally क नाम सँ अलग अछि। “अहाँक Tally मे लेजरक नाम” मे नाम ठीक करू, दुनू फ़ाइल फेर बनाउ, फेर इम्पोर्ट करू।
  • वाउचर टाइप नहि अछि: वाउचर Tally क अपन टाइप इस्तेमाल करैत अछि: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note आ Journal। देखू जे ओ टाइप अहाँक कंपनी मे चालू अछि।
  • टोटल नहि मिलैत अछि: हर वाउचरक डेबिट ओकर क्रेडिट सँ बराबर हेबाक चाही। एतऽ बनल फ़ाइल हमेशा बैलेंस रहैत अछि; ई सिर्फ हाथ सँ एडिट कएल Excel रजिस्टर मे होइत अछि। ओ लाइन ठीक करू।
  • वएह वाउचर दू बेर इम्पोर्ट करब तँ दू बेर बनि जाइत अछि। हर अवधि एके बेर इम्पोर्ट करू।
