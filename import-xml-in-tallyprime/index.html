How to import an XML file in TallyPrime

TallyPrime can read data from XML files (and, from Release 4.0, from Excel too). The files made on this site are XML. The import takes a minute, but the order matters: ledgers first, vouchers second.

Before you start

  • Take a backup of the company in TallyPrime. An import adds entries in one go; a backup lets you go back.
  • Open the right company, and check its financial year covers the dates of the vouchers.
  • For bill-wise details, switch on bill-wise entries in the company features (F11) and keep Maintain balances bill-by-bill on for party ledgers.

Step 1: the ledgers (masters)

  1. Press Alt+O (Import) › Masters.
  2. In File Path, give the folder and the name of the ledgers file, for example tally-masters-2026-11-05.xml in Downloads.
  3. Choose what Tally should do when a ledger of that name already exists: Combine opening balance, Ignore duplicates (keep yours, skip ours) or Modify with new data (ours replaces yours). If your Tally already has these parties set up carefully, choose Ignore duplicates.
  4. Say Yes to the backup, press Enter. Tally shows how many masters were created, altered or ignored.

Step 2: the vouchers (transactions)

  1. Press Alt+O (Import) › Transactions.
  2. Give the path of the vouchers file (tally-vouchers-….xml), say Yes to the backup, press Enter.
  3. Open the Day Book for those dates and compare a few vouchers with your bills.

If Tally reports errors

  • A ledger does not exist: the ledgers file was not imported first, or a ledger name in the vouchers differs from the one in your Tally. Fix the name in "Ledger names in your Tally", make both files again, import again.
  • A voucher type does not exist: the vouchers use Tally's own types: Sales, Purchase, Receipt, Payment, Credit Note, Debit Note and Journal. Check those types are active in your company.
  • Totals do not match: every voucher's debits must equal its credits. Files made here always balance; this happens only with a hand-edited Excel register. Fix that row.
  • Importing the same vouchers twice creates them twice. Import each period once.
